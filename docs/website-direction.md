# Stikr download website

## Direction contract

THESIS: A download page that lets visitors inspect the Android app and try its editor before installing. Real app screens carry the page.

OWN-WORLD: Pure black, dark graphite and forest sections, cream copy and limited folded-S lime accents. Monochrome ASCII jellyfish remain behind content. No neon, coloured background gradients or decorative widgets.

STORY: See the app, try a browser simulation, understand local editing and backups, download the signed Android APK.

FIRST VIEWPORT: Simple navigation, large left-aligned headline and download action, one actual Android pack screenshot at right. Mobile puts the action before the screenshot.

FORM: Product-led split hero, screenshot gallery, interactive demo and sequential setup guide. Production references are Linear typography, Raycast demos and Things app imagery, without copying their assets or claims. seed: none (unavailable).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Content boundaries

The demo is a browser simulation, not an Android emulator. Browser photos stay in the browser. WhatsApp import and on-device cut-out require the Android app. Screens are native Compose captures with example content, not live-device captures. App exports and backups remain local. The website uses the existing GitHub Pages workflow and the single app release download.
