Download Stikr for Android.

Android 8.0 or later. Free, with no account required.

Install on your phone

  1. Download stikr.apk on your Android phone.
  2. Open the downloaded file in your browser or Files app.
  3. If Android asks, allow the app that opened the APK to install unknown apps.
  4. Tap Install, then open Stikr. You can turn off that installation permission afterward.
Make your first sticker

Update without losing your packs

Download the latest APK from this website and install it over your current Stikr app. The download uses the same signing key, so normal updates keep your packs.

Before uninstalling or switching phones, use the folder icon on Stikr's home screen to save a local backup file outside the app. Reinstall Stikr and choose Restore from file to recover that backup.

How local backups work

For WhatsApp and cut-out

Install WhatsApp or WhatsApp Business to import sticker packs. Normal packs contain 3 to 30 stickers. The app keeps single stickers in a shared Stikr pack.

Automatic background removal needs Google Play services and its on-device model. Its first download needs a connection. If cut-out is unavailable, you can keep the full photo.
