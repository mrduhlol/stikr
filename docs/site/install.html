01 / Get the app

Install stikr.

Android 8.0 or newer. Download the signed APK from GitHub Releases.

Install on your phone

  1. Download stikr.apk on your Android phone.
  2. Open the downloaded file from your browser or Files app.
  3. When Android asks, allow Install unknown apps for the app that opened the APK.
  4. Tap Install, then open stikr.

You can turn off that installation permission after installing stikr.

Make your first sticker ↗

Update a release

Download and open the latest signed release APK. Releases use the same persistent signing key, so a new version installs over an earlier release.

If you installed a debug build, uninstall it before installing a release. Android rejects an update with a different signature. Uninstalling removes the app's local packs, so share stickers you want to keep first.

CI debug APKs use a throwaway key on each runner and cannot update one another. Use tagged releases for everyday installs.

Before your first cut-out

Automatic background removal requires Google Play services. The segmentation model downloads on first use, so that initial setup needs a connection. If cut-out is unavailable, stikr keeps the full photo and exposes the cut-out toggle.

For WhatsApp import, install WhatsApp or WhatsApp Business and put 3–30 stickers in your pack. You can also share a single sticker as a PNG.
