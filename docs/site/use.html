Make your first sticker.

Choose a photo, edit it, and save it to a pack.

Create a single sticker

  1. Tap Create a sticker on the home screen and choose a photo.
  2. Keep the full photo or turn on background removal. Outlines start off. Adjust the outline thickness or rounded corners if you want them.
  3. Type in Your text. Choose a font, text colour and optional background. Drag text on the canvas, pinch to resize, and twist with two fingers to rotate.
  4. Use the controls below Your text for bold, italic, underline, strikethrough, alignment and rotation. Add another text layer when you need one.
  5. Choose Save only, or complete Slide to add to WhatsApp. The slider saves your sticker to the shared Stikr pack before asking WhatsApp to import it.

Create and edit a pack

Choose Create a sticker pack, enter a name and author, then select your photos. Leave the title blank for a random name. Each pack holds up to 30 stickers.

Open a pack and tap a sticker to edit it. Pack edit applies a common look and text to the entire pack. Your stored originals stay available for later edits.

Use the three-dot menu to change the thumbnail, title or author. A photo thumbnail uses a 3:4 portrait crop. The level tab has 25 segments that track the pack's 30-sticker capacity.

Add stickers to WhatsApp

Complete the slider in a pack and confirm the import in WhatsApp or WhatsApp Business. Normal packs need at least 3 stickers.

For a saved single sticker, long-press it on the home screen, choose Add to WhatsApp, then complete the slider. Single stickers use the shared Stikr pack. Adding more updates that pack rather than making a duplicate.

You can also tap a sticker in its pack and choose Share to send it as a PNG through Android's share sheet.

Save and restore a backup

  1. Tap the folder icon on Stikr's home screen.
  2. Choose Save backup file and select a location outside the app's private storage.
  3. Keep the ZIP file before uninstalling or moving to another phone.
  4. To recover it, open Stikr, tap the folder icon and choose Restore from file.

Backups are manual local files. Stikr has no account connection or automatic cloud backup. Restore keeps existing local packs and merges the backup.

Try the website demo

The browser demo lets you choose a photo and try text editing. It is a simulation of the Android editing flow. Install the app for WhatsApp import and automatic background removal.
