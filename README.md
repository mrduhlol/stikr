## Features

- Create individual stickers or turn multiple photos into packs.
- Remove backgrounds, adjust outlines, and add text with fonts and colours.
- Personalise pack covers with a photo or styled text.
- Add packs to WhatsApp or WhatsApp Business, or share stickers individually.
- Save and restore your collections with local backup files.

## Install

Download the APK above, open it on your phone, and allow installation from this source if Android asks. Install updates over the existing app to keep your collections.

**Keep your stickers:** use the folder icon → **Save backup file** and save the ZIP to Downloads before uninstalling. After reinstalling, choose **Restore from file**. Backups are manual. [Backup guide](docs/local-backup.md)
